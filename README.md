# QuotePilot — Static Demo (GitHub Pages)

This branch is the **static demo only** for GitHub Pages.

It is a client-side prototype: qualify + 3-tier proposal builder with localStorage and share via URL hash. No backend, no auth, no database.

The full web SaaS (Node + Express + SQLite, auth, DB-backed sharing, pipeline, PWA) lives on the `master` branch in `quotepilot-web/`. See `master` README.md, DEPLOYMENT.md, and SECURITY.md.

To view the demo: open `index.html` (GitHub Pages serves this branch at root).
